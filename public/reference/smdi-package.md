# smdi: Perform Structural Missing Data Investigations

An easy to use implementation of routine structural missing data
diagnostics with functions to visualize the proportions of missing
observations, investigate missing data patterns and conduct various
empirical missing data diagnostic tests. Reference: Weberpals J, Raman
SR, Shaw PA, Lee H, Hammill BG, Toh S, Connolly JG, Dandreo KJ, Tian F,
Liu W, Li J, Hernández-Muñoz JJ, Glynn RJ, Desai RJ. smdi: an R package
to perform structural missing data investigations on partially observed
confounders in real-world evidence studies. JAMIA Open. 2024 Jan
31;7(1):ooae008.
[doi:10.1093/jamiaopen/ooae008](https://doi.org/10.1093/jamiaopen/ooae008)
.
