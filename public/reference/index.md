# Package index

## All functions

- [`smdi_asmd()`](https://janickweberpals.gitlab-pages.partners.org/smdi/index/reference/smdi_asmd.md)
  : Computes mean/median absolute standardized mean differences between
  observed and missing observations
- [`smdi_check_covar()`](https://janickweberpals.gitlab-pages.partners.org/smdi/index/reference/smdi_check_covar.md)
  : This is a utility function to help check input data and covariates
  provided
- [`smdi_data`](https://janickweberpals.gitlab-pages.partners.org/smdi/index/reference/smdi_data.md)
  : smdi exemplary lung cancer dataset
- [`smdi_data_complete`](https://janickweberpals.gitlab-pages.partners.org/smdi/index/reference/smdi_data_complete.md)
  : smdi exemplary lung cancer dataset (with complete data)
- [`smdi_diagnose()`](https://janickweberpals.gitlab-pages.partners.org/smdi/index/reference/smdi_diagnose.md)
  : Computes three group missing data summary diagnostics
- [`smdi_hotelling()`](https://janickweberpals.gitlab-pages.partners.org/smdi/index/reference/smdi_hotelling.md)
  : Computes hotelling's multivariate t-test
- [`smdi_little()`](https://janickweberpals.gitlab-pages.partners.org/smdi/index/reference/smdi_little.md)
  : Computes Little's test
- [`smdi_na_indicator()`](https://janickweberpals.gitlab-pages.partners.org/smdi/index/reference/smdi_na_indicator.md)
  : Create binary missing indicator variables by two different
  strategies
- [`smdi_outcome()`](https://janickweberpals.gitlab-pages.partners.org/smdi/index/reference/smdi_outcome.md)
  : Computes association between missingness and outcome
- [`smdi_rf()`](https://janickweberpals.gitlab-pages.partners.org/smdi/index/reference/smdi_rf.md)
  : Computes random forest-based AUC
- [`smdi_style_gt()`](https://janickweberpals.gitlab-pages.partners.org/smdi/index/reference/smdi_style_gt.md)
  : Takes an object of class smdi and styles it to a publication-ready
  gt table
- [`smdi_summarize()`](https://janickweberpals.gitlab-pages.partners.org/smdi/index/reference/smdi_summarize.md)
  : Utility helper to give a light summary of partially observed
  covariates
- [`smdi_vis()`](https://janickweberpals.gitlab-pages.partners.org/smdi/index/reference/smdi_vis.md)
  : Quick ggplot2 barchart visualization of partially observed/missing
  variables
